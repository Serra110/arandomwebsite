O método de Borda é um sistema eleitoral criado por Jean-Charles de Borda, em que os candidatos recebem pontos conforme a posição em que são classificados pelos eleitores


Exemplo:
	•	1.º lugar → 3 pontos
	•	2.º lugar → 2 pontos
	•	3.º lugar → 1 ponto
	•	4.º lugar → 0 pontos

Quem tiver mais pontos ganha.
Os eleitores ordenam os candidatos
↓
	2.	Cada posição vale pontos
↓
	3.	Somam-se os pontos
↓
	4.	Ganha quem tiver mais pontos
Exemplo de votação

Candidatos:
	•	Ana
	•	Bruno
	•	Carla

Votos
Eleitor	1.º	2.º	3.º
João	Ana	Carla	Bruno
Maria	Bruno	Ana	Carla
Pedro	Ana	Bruno	Carla
(3 candidatos → 2 pontos, 1 ponto, 0 pontos)
